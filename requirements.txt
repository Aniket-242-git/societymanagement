# ============================================================
# Society Management System — Python Dependencies
# TUNED FOR SHARED HOSTING ("C plan": cPanel / Hostinger /
# GoDaddy-style Linux shared hosting).
#
# Constraints respected:
#   - pure-Python, low-memory packages only (no pandas / numpy)
#   - no build-toolchain packages (argon2-cffi needs libargon2)

#     psycopg is optional & commented

#     no daemons) -> notifications run synchronously instead;
#     cron jobs are supported via Django management commands
#
# Install on shared hosting (SSH):
#   python3 -m venv venv && source venv/bin/activate
#   pip install -r requirements.txt
# ============================================================
